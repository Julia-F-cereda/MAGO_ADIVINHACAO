<h3>DESCRIÇÃO DO PROJETO</h3>
Este projeto foi desenvolvido como uma brincadeira matemática interativa, chamada "Rei dos Magos".
A aplicação funciona como um jogo onde o usuário escolhe um número final desejado e um número inicial, e o sistema realiza uma sequência de operações matemáticas que sempre resultam no número escolhido.

<h3>COMO EXECUTAR</h3>
<P>1. Baixe os arquivos do projeto.</P>
<P>2. Abra o arquivo `index.html`.</P>
<P>3. Execute utilizando a extensão Live Server no VS Code.</P>

<h3>FUNCIONALIDADES DO PROJETO</h3>

<P>Iniciar jogo com número personalizado</p>
<P>Jogar novamente</p>
<P>Explicação da lógica matemática por trás da “mágica”</p>
<P>Interação dinâmica utilizando alertas e prompts</p>
<P>Interface simples estilizada com CSS</p>
